# Search Authority — SEO Service Website

A dependency-free, responsive SEO agency website designed for GitHub + Vercel.

## 1. Customize first

Open `index.html` and replace:

- `YOUR-DOMAIN.vercel.app`
- `YOUR_FIVERR_USERNAME`
- `YOUR_UPWORK_USERNAME`
- `YOUR_LINKEDIN_USERNAME`
- `YOUR_EMAIL@example.com`

Also replace the sample case-study numbers (`XX`) with verified results only.

## 2. Run locally

Because this is static HTML, you can open `index.html` directly.

For a local dev server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## 3. Deploy to Vercel

### GitHub
1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Commit and push.

### Vercel
1. Import the GitHub repository into Vercel.
2. Framework preset: **Other**.
3. Build command: leave blank.
4. Output directory: leave blank / root.
5. Deploy.

Vercel will serve `index.html` directly.

## UX / conversion journey

1. **Hero** — visitor immediately understands SEO + AI-search positioning and sees marketplace credibility.
2. **Proof strip** — Fiverr, Upwork and LinkedIn reduce trust friction.
3. **Services** — seven services are explained in business language rather than jargon alone.
4. **Method** — makes the engagement feel systematic and senior-led.
5. **Proof** — case studies are deliberately placed before the final CTA; replace samples with real evidence.
6. **About / credentials** — reinforces the freelancer-to-specialist positioning.
7. **CTA** — one low-friction action: start a strategy conversation.

## Important

Do not publish invented awards, client logos, review counts, revenue figures, ranking claims or case-study results. Replace placeholders with your actual proof.
